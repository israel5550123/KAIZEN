Assim, `ssh`, `scp`, `docker secret`, a remoção de stack e o que o `guarda-bash.js` bloqueia continuam abertos pelo PowerShell. Nada foi mudado: o `settings.json` e os hooks são do dono. · Documentação do Claude Code: [Permissions](https://code.claude.com/docs/en/permissions.md), seção "PowerShell" (as regras têm a mesma forma, com o prefixo `PowerShell(...)`); [Hooks](https://code.claude.com/docs/en/hooks.md) (o matcher filtra pelo nome da ferramenta; `"Bash|PowerShell"` pega as duas). · Para fechar esse caminho: repetir no `deny` cada regra com o prefixo `PowerShell(...)` (por exemplo, `PowerShell(ssh *)`) e trocar o matcher do `guarda-bash.js` para `"Bash|PowerShell"`. Na Fase 4, a regra do `allow` do script também precisaria da forma equivalente, se o script for chamado pelo PowerShell.
